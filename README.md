# Tesis de Maestría

Este repositorio contiene el manuscrito LaTeX de la tesis de maestría de Miguelángel Díaz Cerecetto.

- [Ver o descargar el PDF compilado](https://diazcerecetto.github.io/clickbait/tesis.pdf)
- [Abrir la página de la tesis](https://diazcerecetto.github.io/clickbait/)

El PDF se vuelve a compilar y publicar automáticamente cuando se actualiza el manuscrito.
